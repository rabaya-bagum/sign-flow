# Bundled fonts

Script fonts for typed signatures and initials (SPEC §5.7). All three are licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org), which allows bundling and embedding them in
documents. Each licence file below carries the font's copyright line. Source: Google Fonts, via the
`@expo-google-fonts/*` packages (version 0.4).

| File                         | Font                    | Licence                 | `font_key`       |
| ---------------------------- | ----------------------- | ----------------------- | ---------------- |
| `DancingScript-SemiBold.ttf` | Dancing Script SemiBold | `OFL-DancingScript.txt` | `dancing-script` |
| `GreatVibes-Regular.ttf`     | Great Vibes Regular     | `OFL-GreatVibes.txt`    | `great-vibes`    |
| `Caveat-Medium.ttf`          | Caveat Medium           | `OFL-Caveat.txt`        | `caveat`         |

`font_key` is stored with typed saved signatures. Never rename a key: saved rows refer to it.
